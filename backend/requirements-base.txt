# Everything the application needs to import.
#
# This file exists so that CI and production install the *same* list rather
# than two lists that drift apart. `requirements.txt` adds the three heavy
# packages on top of it; `requirements-dev.txt` adds the test tooling. Neither
# restates what is here.
#
# The split is possible because those three heavy packages — chromadb,
# sentence-transformers and scrapling — are imported lazily, inside the
# function that first needs them, rather than at module scope. Importing the
# application therefore does not require them; only opening a vector store,
# loading a local embedding model or reaching the scraper's second rung does.
# Keep it that way: a top-level import of any of them silently makes this file
# incomplete, and the failure surfaces as a CI collection error rather than as
# anything that names the cause.
