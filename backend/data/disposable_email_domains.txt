# Disposable / throwaway email domains refused at sign-up.
#
# Read once at import by services/email_guard.py. One lowercase domain per line;
# blank lines and `#` comments are ignored. Matching walks the parent domains,
# so listing `mailinator.com` also blocks `anything.mailinator.com` — which is
# how these services hand out addresses, and why an exact-string list would be
# almost useless.
#
# This is a pragmatic subset of the public `disposable-email-domains` project,
# weighted towards the services that actually show up in sign-up spam. It will
# never be complete: the throwaway providers register new domains faster than
# any list is updated. It is a speed bump, not a wall — the confirmation email
# Supabase sends is the check that actually proves a mailbox exists.
#
# To extend it, append domains and keep the file sorted. No code change needed.
